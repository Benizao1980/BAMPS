# Release checklist

- [ ] All scripts compile and `pytest` passes.
- [ ] Example commands run in a clean environment.
- [ ] Dependency versions are captured.
- [ ] README and CITATION metadata match the release version.
- [ ] No private data, credentials, absolute local paths or generated models are committed.
- [ ] Create an annotated Git tag/release (for example `v0.1.0`).
- [ ] Archive the GitHub release with Zenodo.
- [ ] Add the Zenodo DOI badge and DOI to `CITATION.cff` after minting.
